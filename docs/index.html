About this dashboard

Everything here is generated from one data file (grants-data.json) that is rebuilt automatically once a week by a GitHub Action. Each run blends four sources:

  • Curated — hand-researched, high-value local funders that have no public API.
  • Federal — live housing & community-development opportunities from the Grants.gov API.
  • Prospects — Oregon & SW-Washington grantmakers pulled from IRS 990 data (ProPublica), plotted on the Local Funders map.
  • PNW News — Pacific-Northwest housing, funding, and policy headlines scanned from Google News and curated by topic.
