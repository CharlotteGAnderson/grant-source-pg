    About this dashboard

    Everything here is generated from one data file (grants-data.json) that is rebuilt automatically on a schedule by a GitHub Action. Each run blends three sources:

    • Curated — hand-researched, high-value local funders that have no public API.
    • Federal — live housing & community-development opportunities from the Grants.gov API.
    • Prospects — Oregon & SW-Washington grantmakers pulled from IRS 990 data (ProPublica).
